# 2022~2026 공식 반영비율을 반영한 2027 정시 예측 모델

## 과거 학년도는 실제 해당 연도의 계산법을 적용

과거 한 명의 9평 성적표와 그 학생의 실제 해당 학년도 정시 **지원·합불**을 확인한
자료만 학습합니다. 해당 연도 모집단위와 대입요강 공식 출처가 등록되지 않으면 제외합니다.

\`2022년 9평 성적표 -> 2022학년도 대학별 변표·국수탐 반영비율·영어/한국사·가산점 -> 환산점수\`
를 계산합니다. 2023, 2024, 2025, 2026학년도도 각각 **그 해의 공식 규칙**만 사용합니다.
각 대학 환산총점으로 나눈 점수는 모형의 입력 변수일 뿐, 모든 대학과 연도에 걸쳐
그 값 자체가 동등한 합격선이라는 가정은 하지 않습니다. 과도한 반영비 변동이 있으면
기존 학년도를 부적합 표본으로 제외합니다.

2027학년도에는 2027학년도 공식 모집요강으로 계산된 성적표의 환산점수로
오프라인 사전 산출 확률곡선을 조회합니다. 과거 70%컷은 개별 합불 레이블로 사용하지 않습니다.

### 개인 비공개 JSONL (Git에 커밋하지 않음)

각 줄에 **실제 개인 1인의 실제로 지원한 모집단위 1건**만 입력합니다.

\`\`\`json
{"year":2025,"exam_type":"september","program_key":"verified-major-key","applicant_hash":"16chars-or-longer-opaque-key","applied":true,"verified":true,"consented":true,"admitted":1,"student":{"korean_pct":98,"math_pct":97,"english_grade":1,"history_grade":1,"math_track":"calculus","inquiries":[{"name":"물리학Ⅰ","kind":"science","pct":95},{"name":"화학Ⅰ","kind":"science","pct":94}]}}
\`\`\`

해당 대학·해당 학년도 환산법이 표준점수 기반이면 성적표의
\`korean_std\`, \`math_std\`, 탐구 각 과목의 \`std\`도 필요합니다.
변표가 백분위 기반이면 과목별 공식 \`pct\`와 해당 대학 연도의 변표가 필요합니다.
임의 표준점수·백분위 역산은 금지합니다.

현재 GitHub에는 2022~2026학년도 범위 내 대학별 공식 환산식 및 검증된 실제 지원·합불
원자료가 없으므로 **예측 퍼센트는 생성되지 않습니다.**

### 모델 공개 허용 기준

- 동일 모집단위 2022~2026학년도 실제 9평 성적·실제 합불을 연도별 규칙으로 계산
- 2025·2026학년도 **순행 홀드아웃** (해당 연도 결과를 사전 학습하지 않음)
- 최소 연도·표본 수, 양/음성 균형, AUC, Brier/기준선, 예측률-관측률 편차 검증
- 해당 대학·학과 공식 가중치 변화폭이 크면 **전이 검증 전까지** 예측값 보류
- 오직 연도·대학·학과·검증지표·사전 계산 **점수 조건부 곡선**만 공개

학습 실행:
\`\`\`sh
python -m scripts.historical_forecast \
 --private-input /secure/path/historical_september_with_actual_outcomes.jsonl \
 --output data/public/models/historical-2027.json
\`\`\`

**주의:** 과거 수능 성적표만 있고 9월 모의평가 성적표가 없다면 이 모델의
학습 재료로 사용할 수 없습니다. 수능 성적표로 학습한 모델을 9평 입력에
그대로 적용하는 것은 시험 시점 불일치입니다. 별도로 엄격한 검증을 마친
수능-9평 변환 모델이 있을 때만 연계할 수 있습니다. 향후 Supabase 비공개
데이터 수집이 연결될 때에도 개인 원본은 GitHub Pages에 절대 공개하지 않습니다.
