# 공식 대학별 변환표준점수표 등록 위치

해당 연도 해당 대학 원문에 발표된 변표만 CSV로 등록합니다. **2027학년도 자료는 아직 등록하지 않았습니다.**
같은 ‘표준점수 65’라도 대학과 탐구과목에 따라 변환점수가 다릅니다. 표를 찾지 못하면 값을 보간하거나 타 대학 표를 재사용하지 않고 **계산 불가**로 표시합니다.

필수 열:
\`year,university,table_id,subject,std_score,converted_score,source_url,last_verified\`

대학 모집단위 반영비율과 각 영역의 산출식은 \`data/public/programs/*.csv\`의
\`formula_id=weighted_official_v1\`, \`formula_config_json\`으로 관리합니다.
설정 JSON에 학년도·대학·모집단위, 국어·수학·영어·탐구 반영비율,
표준점수 또는 백분위 사용 여부, 변환표 ID, 영어 등급 환산, 한국사 가산점,
수학 선택과목 가산점, 탐구 1/2과목 반영과 지원 자격을 명시합니다.

공개된 대학별 공식 총점 산출 예시와 반드시 대조한 뒤 \`last_verified\`를 기록하세요.


### 탐구 백분위 기반 변환표 (대학별 특성)

공식 백분위별 변환표를 확인한 경우에는 `pct-*.csv` 파일로 보관합니다.
필수 열: `year,university,table_id,subject,percentile,converted_score,source_url,last_verified`.
이는 표준점수로 변환표를 찾는 일반 CSV와 **다른 인덱스**입니다. 표준점수 → 백분위 값을 추정해 채우지 않습니다.

공식 `formula_config_json`의 탐구 계산 부분에
`"metric":"converted_pct"`을 지정하고, 과탐 가산이 변표 점수 자체에 더해지는 경우
`"kind_bonus_points":{"science":4}`로 설정할 수 있습니다.
영어·한국사를 등급 감점으로 사용하는 경우 `grade_point_adjustments`에
영어 및 한국사 등급별 **실제 감점 점수**를 별도로 명시합니다.

이 기능을 사용할 수 있다는 것은 2027학년도 특정 대학의 최종 변표가
검증·입력됐다는 의미가 아닙니다. 공식 원문과 대학의 총점 예제를 비교 검산한
후에만 실전 모집단위 규칙으로 승인합니다.


## 실물 변표 첫 등록: 2025학년도 숭실대학교 일반전형

- 공식 대입정보포털의 **2026학년도 자료에 첨부된 2025학년도 실제 변표**(백분위 100~0 전체 101행, 사회·과학 통합)를 `pct-2025-soongsil-regular.csv`로 수치 검수 후 등록했습니다.
- 동일 사회·과학 변표를 사용하기 때문에 `subject=*`를 지원하되 **social/science 탐구에만** 적용합니다. 직업탐구 전형의 다른 변표로 자동 대체하지 않습니다.
- 확인용 예시: 백분위 100→70.00, 99→69.08, 91→64.18, 88→63.10, 83→61.34, 0→30.71.
- 출처: [대입정보포털 숭실대 2026 전형 정보 내 ‘2025학년도 신입학 정시 탐구영역 백분위 변환표준점수표’](https://www.adiga.kr/ucp/uvt/uni/univDetailSelection.do?menuId=PCUVTINF2000&searchSyr=2026&unvCd=0000143). **2026학년도 변표가 아닙니다.**
