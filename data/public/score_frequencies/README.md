# 시험별 공식 표준점수 도수분포

이곳에는 교육부/한국교육과정평가원에서 공개한 표준점수별 실제 인원수를 원문 대조 후 CSV로 등록합니다. 2027학년도 9월 모의평가 25개 영역·과목, 1,065개 점수 도수분포 행을 첨부 원본에서 검증 후 등록했습니다. 다른 시험은 아직 미등록입니다. 시험 문제지나 확정 등급컷만으로 도수분포를 꾸며 넣지 않습니다.

열: `year,exam_type,subject,option_name,std_score,examinee_count,source_url`

- `exam_type`: `september` 또는 `csat`; `year`: 입학 학년도 2022–2027 (`2027/csat`은 시행 전이므로 입력 거부).
- `subject`: 시험 통계 원문에 표시된 국어/수학/탐구 구분 또는 탐구 과목명 그대로 작성.
- `option_name`: 원문에 선택과목별 도수분포가 있는 경우에만 해당 선택과목을 기입; 전체 영역만 공개된 경우 `all`. 서로 다른 통계 모집단은 절대 합치지 않음.
- `std_score`: 표준점수, `examinee_count`: 해당 표준점수 인원수(0보다 큰 정수).
- `source_url`: 실제 도수분포를 대조한 공식 HTTPS 원문 URL.

**중요:** 같은 전국 분위에 놓인 9평과 수능의 표준점수를 비교하는 것으로 동일 학생의 9평→수능 성적 변화가 아닙니다. 2027 수능 예상점수는 역사적 분포변화를 전이한 시나리오이므로 실제 합격확률로 표기하지 않습니다. 도수분포가 아닌 1~9등급 경계만 있다면 정밀 분위 보정 계산은 중단됩니다.
