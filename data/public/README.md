# 공개 데이터 적재 영역

`programs/`에는 공식 원문과 학년도를 수작업 검증한 **모집단위/전형 자료** CSV만 보관합니다.

- 개인별 성적·지원 대학·합불 여부 등 실측 개인 데이터는 GitHub에 업로드하지 마세요.
- `tools/import_programs.py`가 받는 형식으로 작성하고, 산식 코드는 구현·검증된 것만 등록합니다.
- 공식 출처 URL과 학년도를 함께 보관합니다. 서로 다른 학년도 반영식/입결을 섞지 않습니다.
- 공식 모집요강/변경 공고 확인이 끝날 때까지 빈 상태가 정상입니다.
- GitHub Actions 주간 감사는 **공개 저장소의 CSV를 검사**할 뿐, 대학 사이트를 긁어 최신 데이터를 자동 확보하지 않습니다.
