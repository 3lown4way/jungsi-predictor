# 전 대학 2022~2026 자료 검증 매트릭스

\`scripts/historical_coverage_matrix.py\`는 정시렌즈의 20개 일반대학 × 5개년을
**100행**으로 유지합니다. 자료가 수집될 때마다 아래 단계를 각각 확인합니다.

1. 해당 연도 공식 입학처/어디가 자료 진입점
2. 모집계열별 공식 국·수·영·탐 반영비율/가산점
3. 공식 탐구 백분위→대학 변환표준점수 전체 값
4. 원문 계산 예제와 일치하는 해당 연도의 **수능** 환산
5. 해당 연도 공식 9평 점수에서 수능 환산점수로의 검증된 보정
6. 실제 개인별 9평 점수와 당시 지원·합격 결과의 비공개 검증 표본
7. 연도 순행 백테스트를 통과한 **2027 대학별 합격확률곡선**

입결 70% 컷은 5번 또는 6번을 대체할 수 없습니다.
공식 사이트 URL을 찾았다는 것만으로 2~7을 완료 처리하지 않습니다.

\`\`\`sh
python -m scripts.historical_coverage_matrix --output audit/historical-coverage.json
python -m pytest tests/test_historical_coverage_matrix.py -q
\`\`\`

위 매트릭스는 역사적 **연구·학습 데이터 준비 현황**이며 웹사이트 메인에는 공개하지
않습니다. 사이트는 2027학년도 대학·학과 합격 전망이 메인입니다.
