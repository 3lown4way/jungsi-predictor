# 정시렌즈 v1.0 · 2027학년도 9평 공식 성적표 기반 대학·학과 합격 전망

2027학년도 9월 모의평가의 **국어·수학·탐구 공식 표준점수(선택과목 포함), 영어·한국사 등급, 필요한 공식 백분위**를 입력해 대학별 환산점수를 계산할 수 있도록 구성한 연구용 MVP입니다. 대학·모집단위별 환산식은 학년도별 원문 검증 후 등록하고, 합격확률 ML은 GitHub Actions 오프라인 학습·검증 후 점수조건부 결과로 게시합니다. 현재 대상 학교의 2027학년도 공식 반영식·과거 개인 실측 합불 데이터 및 검증된 합격확률 곡선은 미등록 상태이며, 학교별 합격률을 만들어내지 않습니다.

- **일반대학 20곳(가나다 아님, 순위 아님)**: 서울대, 연세대, 고려대, 서강대, 성균관대, 한양대, 중앙대, 경희대, 한국외대, 서울시립대, 이화여대, 건국대, 동국대, 홍익대, 숙명여대, 국민대, 숭실대, 세종대, 아주대, 인하대. 이 목록은 잠정 작업 명단이며 **`app/scope.py`의 `TOP_20`**에서 수정합니다.
- **전국 매디컬**: 의예·의학, 치의예·치의학, 한의예·한의학, 약학, 수의예·수의학 5개 면허 직결 모집단위. 위 20개 대학 바깥의 학교라도 해당 모집단위면 대상입니다. 연구 범위는 전국이지만 자료가 자동으로 수집되거나 모두 검증된 것은 아닙니다.
- **제외**: 간호학, 의공학, 약과학, 바이오의학 등 비면허 모집단위(위 일반대학 20곳 소속 학과이면 일반전형으로 포함). 구체적인 대학·학과와 전형 구분은 해당 학년도 원문으로 검증합니다.
- **명단과 데이터는 별개**: 명단에 들어 있는 학교라도 그 해 공식 환산식을 확보하지 못했다면 `계산 불가`라고 표시합니다. 가짜 환산점수나 합격률을 만들지 않습니다.
- 기존에 공식 산식 검산에 사용했던 **상명대 2025·2026학년도 12건**은 무손실 보관하지만, 사용자 추천·ML 결과에서는 제외합니다. 진단용 `/api/examples/programs`에서 조회할 수 있습니다.

제한 범위용 엔드포인트: `/api/scope`, `/api/programs`, `/api/calculate`, `/api/backtest`, `/api/meta`.

## 3. DB 설계

`data/admission.sqlite3` 자동 생성. 기존 DB를 보존하는 `programs.medical_field`, `programs.selection_type` 열 추가 마이그레이션 적용. 대상 목록 필터는 `app/scope.py`에서 관리.

| 테이블 | 설명 |
|---|---|
| `programs` | (`year`,`program_key`) 복합키, 학과·모집군·정원·해당연도 산식·같은 연도 70% 컷·각각의 원문출처 |
| `exams` | (`year`,`exam_type`,`subject`,`option_name`,`std_score`)별 표준점수 도수분포와 출처; 향후 공식자료 적재용 |
| `actual_applications` | **실제 지원자만**, 연도별 성적과 합격 여부. 비식별화 해시·동의·검증 상태 및 자료출처 포함 |
| `import_log` | CSV 적재 이력 |

원본 시험지 PDF는 난이도 분포나 대학 입결을 알려주는 데이터가 아닙니다. 등급·도수분포는 별첨 공식 채점 통계, 반영식은 **해당 입학 학년도** 모집요강을 별도로 읽어야 합니다.

## 4. 2022학년도부터 실제 모의지원 머신러닝 검증

`app/ml.py`: `ColumnTransformer(StandardScaler + OneHotEncoder) → LogisticRegression`. 연도별 모집인원, 모집군 및 수학 반영비율도 예측 시점에 알려진 설명변수로 입력합니다.

1. 입력: 합격/불합격이 **확인된, 실제 원서 지원 학생**. 같은 대학이라도 `program_key`로 동일 모집단위를 안정적으로 매핑합니다. 실제 시험의 영역별 백분위·영어등급·수학 선택과목에 더해 **학년도별 모집인원·모집군·수학 반영비율**을 이용합니다. 다른 해의 표준점수 원점수를 같은 특징값으로 사용하지 않습니다.
2. 2023년 테스트는 이전 연도의 데이터가 1년만 존재해 검증/학습 조건에 미달하므로 결과가 없습니다. 2024, 2025, 2026 학년도 테스트는 각 테스트 연도 **미만**의 데이터만 학습해 비교합니다. 2027은 아직 결과가 없어서 불가능합니다.
3. AUC, Brier score, 정확도, 관측 합격률/평균 예측확률을 기록합니다. 실제 합불 라벨이 없으면 **0개의 평가 성공/검증 불가**로 표시합니다.
4. 모델의 최소 학습조건: 100건 + 2개 이상의 서로 다른 연도 + 합/불 각각 15건. 외부 연도별 검증 최소 30건 + 합/불 각각 15건. 대상 학과 지원 표본도 최소 10건. 대상학과 최소 10건과 더불어 최근 2개 연도에서 AUC ≥ 0.60, Brier가 기저 예측보다 양호, 평균 예측/실제 합격률 차이 10%p 이하 조건을 모두 충족해야만 모델 확률을 노출합니다. 기준 미달시 확률 반환 없음. 이 값들은 연구용 임시 게이트로 향후 변경할 수 있습니다.
5. 실제 지원자 데이터는 선택편의·중복지원·추가합격·지원 시점의 경쟁환경을 통제하지 못할 수 있습니다. 일반 학생 집단 전체의 합격 확률로 단정하는 것은 금물입니다. 공개된 70% 컷만 가지고 가짜 불합격자를 생성하면 안 됩니다.
6. 모의평가 성적을 '실제 수능 때도 같은 수준일 것'으로 바꾸는 별도 **모평→수능 학생 단위 종단 데이터**가 아직 없어 모의평가 기반 합격 확률을 보류합니다. `june`/`september` 입력에도 **기계적 환산점수만** 보입니다.

**중요:** 2025 최종등록자 70% 컷은 사후에만 공개됩니다. 이것을 2025년 합격을 사전 예측하는 ML 특징값으로 사용하면 데이터 누출입니다. 현재 ML은 같은 해 확정 컷을 **특징으로 전혀 사용하지 않습니다**.

## 5. CSV 가져오기

제공 양식 `app/static/outcomes_template.csv`을 참고하세요. 실제 데이터 적재는 아래처럼 토큰을 정해 서버를 띄운 후 웹 '데이터 커버리지'에서 CSV 업로드합니다.

```bash
export ADMISSION_ADMIN_TOKEN='길고-추측하기-어려운-관리자-토큰'
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

- 학년도 2022~2026, 실제 해당 모집단위에 지원, 합불 확정, 적법한 데이터 수집·동의, 비식별화 처리, 자료출처 필수.
- 응답의 `verified=1`은 **업로더가 주장하는 검증 상태**입니다. 자동 원본 검증을 의미하지 않습니다. 운영환경에서는 원본 증빙 및 관리자 승인 절차 필수.
- 개발용 로컬 서버입니다. **외부 공개 서버에 보안·개인정보 조치 없이 배포하지 마세요.** 인증 강화, 접근권한, TLS, 데이터 삭제, 감사, 법률 검토가 필요합니다.
- 중복 행/형식 오류는 서버 오류가 나며 전체 업로드가 취소됩니다.

## 8. GitHub Actions / GitHub Pages 운영 (v0.3)

### GitHub 저장소 초기 등록

새 GitHub 저장소를 `jungsi-predictor`로 생성한 뒤, 프로젝트 루트의 파일들을 `main`에 업로드합니다. **개인 성적 원자료, 실제 지원자별 합불 데이터, SQLite 데이터베이스, 관리자 토큰은 Git에 올리지 않습니다.**

본 프로젝트는 공개 저장소 운영을 가정한 **비식별·공개 전형 자료만의 빌드**입니다. 실제 합불 원본 데이터는 별도의 접근통제된 DB에서 관리해야 합니다.

### 자동화 워크플로 3개

| 파일 | 조건 | 수행 작업 |
|---|---|---|
| `.github/workflows/ci.yml` | `main` push / PR / 수동 | Python 3.11·3.12 테스트, 데이터 보안감사, 공개 대시보드 빌드 검사 |
| `.github/workflows/pages.yml` | `main` 코드·공개 데이터 변경 / 수동 | 테스트 → 공개 데이터 검사 → 정적 페이지 생성 → GitHub Pages 배포 |
| `.github/workflows/data-audit.yml` | 매주 월요일 오전 6시(한국시간) / 수동 | 저장소 내 공개 CSV 재검증, 연도별 데이터 커버리지 보고서 업로드 |

### Pages 최초 설정

1. GitHub에서 **Settings → Pages → Build and deployment → Source: GitHub Actions** 선택.
2. 저장소 **Actions** 탭에서 `Deploy public research dashboard to GitHub Pages` 워크플로를 수동 실행하거나 `main`에 코드를 push.
3. 완료 후 화면에 표시되는 배포 URL 열기. 기본형은 `https://<사용자>.github.io/<저장소>/`입니다.

중요: GitHub Pages는 **정적 HTML·JS·JSON**만 서비스합니다. `FastAPI`, `SQLite`, `sklearn` 서버는 Actions가 끝난 뒤 상시 실행되지 않습니다. 기본 배포는 대학 대상 명단, 검증 진행 상황, 연도별 커버리지, 브라우저 로컬 성적 기록 화면만 제공합니다. **환산점수 계산·실측 ML 추정은 현재 범위 내 검증 산식/라벨이 없으며, 외부 API 서버를 별도로 호스팅해야 활성화됩니다.**

### 별도 FastAPI 백엔드 연결 (향후)

배포한 FastAPI 서버가 생기면 저장소 **Settings → Secrets and variables → Actions → Variables**에서 `PUBLIC_API_BASE_URL`을 공개 HTTPS 백엔드 주소로 설정하고 Pages를 재배포합니다. 백엔드에는 `ADMISSION_ALLOWED_ORIGINS=https://<사용자>.github.io`를 지정해 해당 Pages 출처만 교차 도메인 API 접근을 허용합니다. **관리자 토큰과 개인 데이터는 절대 이 공개 변수를 사용하지 않습니다.**

### 로컬에서 Actions 사전 확인

```bash
python -m pip install -r requirements.txt
python -m pytest -q
python -m scripts.audit --output audit-report.json
python -m scripts.build_pages --output site
python -m http.server 8080 --directory site
```

로컬 공개 대시보드: `http://localhost:8080/`.

### 공개 데이터 갱신 규칙

`data/public/programs/`에 검수한 모집요강·입결 CSV를 추가하면 push 후 자동으로 검증·배포합니다. **자동화 주간 실행만으로 대학 홈페이지의 최신 자료를 수집하거나, 기계학습을 새로 학습하는 것은 아닙니다.** 실측 합불 데이터의 권한·동의·증빙 확인과 모델 학습은 별도 비공개 파이프라인이 준비된 이후에만 연동합니다.

## v0.4 — 개인 입력 없는 사전계산 데이터셋

**사용자 요구 변경:** GitHub Pages는 개인 성적 입력 인터페이스가 아니라 `2022~2027학년도 × 시험 유형 × 각 영역별 공식 등급 경계값 조합 × 대학/학과의 해당 학년도 환산식`으로 미리 만든 **공개 데이터셋 조회기**입니다. 기존 FastAPI의 성적 입력 API는 이전 연구용 코드로 남겨두되 Pages 화면에서는 사용하지 않습니다.

- `data/public/grade_boundaries/*.csv`: 확정 채점 결과의 등급별 **공식 경계점수/백분위**와 공식 출처. 예시는 `data/public/grade_boundaries/README.md` 참고.
- `data/public/programs/*.csv`: 대학·학과·연도별 공식 산식/입결, 출처. 산식 플러그인이 구현된 모집단위만 계산.
- `scripts/precompute.py`: 자료를 검증하고 국/수/영/탐1/탐2 각 1~3등급의 **경계값 시나리오**를 미리 계산. 원문에 경계 백분위가 없다면 백분위형 산식을 임의 채우지 않음.
- `scripts/build_pages.py`: `site/data/precomputed-YYYY.json`, `precomputed-summary.json` 생성. Actions로 정적 배포.
- 점수는 각 등급 **하한의 경계값** 시나리오이며 등급 전체의 대표 점수/최저 합격선이 **아닙니다**. 같은 해 등록자 70% 컷 차이는 **사후 비교값**일 뿐 실측 합불, 입학 보장, 검증된 합격확률이 아닙니다.
- 개인별 실제 지원-합격 기록이 확보되면 비공개 데이터로만 학습·연도별 순행 검증하고, 검증 통과 결과만 별도 집계 데이터로 공개합니다.

현재 분석 대상인 주요 20교 및 전국 매디컬의 등급경계 CSV와 산식 플러그인 자료가 아직 비어 있으므로 **사전 계산 행은 0건이 정상**입니다. 다음 단계는 2022~2026학년도 확정 자료를 대학·학년도별로 출처 검수하여 적재하는 것입니다. 2027학년도 확정 수능 컷은 시행 전이므로 없습니다.
